Review before you sign

Import a source-signed consent proposal or key-enrolment challenge. The wallet verifies the institution binding, assigned key, signature and expiry. A signature authorises the specific instruction; it does not prove payment.

Current packages use the SunPhi integration sandbox protocol. They cannot authorise a production payment.

Local test activity

Signed journal verified on every reopen. The test clock starts at day zero. A local journal is not an independent bank statement.

Identity & recovery

This public key must be enrolled by an institution before it can be assigned signing authority.

Keep a separate copy and store its password separately. Restoring an older backup also restores its older local history. It cannot roll back institution records.

Change wallet password

The active file changes. Older backups keep their original passwords. Automatic locking after five minutes without a wallet operation; also on computer sleep or screen lock.

Connection status

Production bank APIs, live balances, hardware-key custody and institution recovery are not connected in this build. No network calls are made by the desktop wallet. SunPhi provides technology; financial institutions define and provide financial services.

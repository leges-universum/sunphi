# Wander 0.15 experimental release

Bounded observer relay signatures advance the original transfer. Exact proposal, role, head and predecessor certificates remain bound. Up to two on-demand relay peers and a second coordinator route are available; successful votes are independently verified. Healthy observations retain usable signatures in a bounded head-scoped cache. Omission remains suspicion, never proof of malicious intent. Finality quorums and durable locks are unchanged.

Nine isolated 100-process scenarios passed, including source-selective L2/L3/L4 refusal, alternate coordinator, lost final response, false complaint, concurrent conflicting spends and quorum loss/reconnection. These are experimental checks, not production certification. The public gateway still has a single ingress; routes do not establish independent operators.

Public signed manifests only. Bridge retains 0.14 plus 0.15; the final certified policy allows 0.15. GitHub publication alone does not activate a release. File hashes are not hostile-host execution attestation.

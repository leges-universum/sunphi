# Wander 0.14 experimental release

Signed executable manifests for bounded stalled-transfer observation and safe automatic controller reassignment. Bridge retains the prior recovery policy and both executable releases; activation of version2 requires a certified policy transaction after runtime and browser-verifier upgrades.

Observers reproduce the actual failed L2/L3/L4 signing stage. A complaint is not authority to exclude a node. Reassignment still requires the existing global quorum and preserves durable consensus locks. Omission may mean delay, not malicious intent; adaptive selective service can evade detection. Exact-request validation caching is bounded and invalidated at a new certified head; admission, signing, executable-integrity and finality checks remain live.

Seven isolated 100-process scenarios and 118 Linux checks passed. The network scenarios include refusals while LIFE works, false complaints, stale evidence, one conflicting-spend outcome and fee, and controller restart. One run was resumed after a replacement L4 group contained the same four refusing identities: random rotation cannot guarantee availability in one attempt. These are experimental checks, not an audit or production-security certification.

GitHub publication does not activate policy. Publisher signatures authenticate approved files, not execution on a hostile host. Public keys and manifests only; no private node, wallet or publisher keys.

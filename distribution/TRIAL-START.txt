SUNPHI TRIAL 0.18.15 — WINDOWS NODE + UNIFIED WALLET / LINUX NODE
Current chain: sunphi-lab-wan-20261030-a. Test tokens only.

WINDOWS (this laptop and each remote computer)
1. Download and extract the COMPLETE ZIP into a short new folder, e.g. D:\SunPhi. Do not overwrite a
   running installation or an existing wallet. Open SunPhi Native Node.exe.
2. Choose Network and select Connect to Network. Each computer creates its own
   transport key. No connection request or administrator approval is needed.
3. Keep the application open. Secure connections and history synchronization
   start automatically. After a disconnect the client retries safely.
   Coin is a separate institutional connection screen; no live institutional
   node profile is supplied in this release. It does not reuse Network admission.
4. The local height should grow, synchronization should complete, voting power
   stays zero. Open wallet enters the integrated wallet. Back to node locks it.
5. In the wallet choose Coin or Network. Switching directions locks the previous
   session. Coin preserves the institutional demonstration wallet, its holdings,
   transfers, history, support and security. Existing Coin 0.5 encrypted files
   open in Coin. No live bank is connected. Network uses a separate encrypted
   file for the new trial; there is no automatic conversion of older balances.
   Create a new encrypted Network wallet, save a backup, and allow the
   initial history check to finish. It can take several minutes. Unverified or
   unavailable balance is never presented as spendable. Starting a node does
   not grant tokens, validator votes, issuance rights or income.

Windows 10/11 x64; OpenSSH Client (ssh.exe and ssh-keygen.exe) must be installed.
Other runtimes are included; no Node.js or WSL installation required.
Suggested: 8 GB RAM, 16 GB for local ZK proving; 3 GB free plus growing history.
The executable is unsigned. Verify SHA256SUMS.txt. Startup after Windows sign-in
is optional: enable the checkbox only after choosing a permanent folder. No
service or firewall rule is installed. Sleep/disconnection suspends participation.

Windows device state: %APPDATA%\SunPhi Native Trial\node\trial
Wallet files: the location YOU choose. Retain them and their encrypted backups.
An update uses the same Windows account and retains device state. Close the old
client before starting the new one. Do not copy the device state to another PC.
This client uses local ports 34000/34001,34030/34031,34060/34061,34100–34109,
34200–34202 and 34400–34403. It does NOT replace the existing laptop WSL validators.
Only outbound pinned SSH on TCP2244 to the three Network servers is needed.

LINUX x86_64
Extract the complete tar.gz. OpenSSH client is required. From its directory:
  ./sunphi-trial.sh connect "$HOME/.sunphi-trial"
Keep running; Ctrl+C stops only this client. Reuse the same state directory.

SECURITY / LIMITS
The public package includes genesis, verifier, transport host pins and public
witness roots. It includes NO node private key, bank credential or wallet secret.
Device transport and non-voting node keys are generated locally. Admission does
not alter the 7-of-10 committee. All local services remain loopback-only.
Public source tags and checksums establish release consistency, not an independent
security audit. Trial network has four execution hosts under one administrator.
32 provisioned witness generations are finite (~7.5 days from chain launch at
the nominal rate); operators must extend them before exhaustion. Failure to renew
blocks new financial readiness, never bypasses verification. No real-money use.
Coin and Network share one interface, with separate file formats, keys and
balances. The original browser wallet remains at its existing address. Older
network key revocation, reward-registration and controller-admin actions do not
apply to the new protocol. Its Security page states these differences explicitly.
Both directions lock on switching and screen lock; five-minute inactivity lock.
Native preparation always uses a zero-knowledge proof. Confirm the saved payment
separately. Recovery checks its exact original identifier; it never invents a new
payment after a lost reply. Keep the file and password; there is no password reset.

РУССКИЙ КРАТКИЙ ПОРЯДОК
Распакуйте ZIP целиком в короткую папку, например D:\SunPhi, запустите SunPhi Native
Node.exe. Выберите Network и нажмите Connect to Network. Ручной допуск не требуется.
На каждом компьютере создаётся собственный ключ подключения.
Подключение и проверка истории начнутся автоматически. Open wallet открывает
кошелёк внутри приложения. Оставляйте приложение открытым. При обновлении не
удаляйте данные и не копируйте ключи узла на другие компьютеры. Реальные деньги
в этой сети не используются; подключение само по себе не начисляет токены.
В кошельке выберите Coin или Network. Coin сохраняет прежние финансовые разделы
и открывает файлы Coin 0.5. Network — новая испытательная сеть, отдельный файл.
При смене направления открытый кошелек блокируется. Остатки не смешиваются.
Восстановлены прежняя компоновка Network, три формы входа и семь разделов.

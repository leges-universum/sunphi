DueByte Linux node management

Server: installation enables the local management service at
http://127.0.0.1:28080/. For a remote server, forward that port with your normal
SSH client and open the forwarded localhost address. The service is deliberately
bound to localhost. Do not publish it through an unauthenticated reverse proxy.
Initial management password:
/var/lib/duebyte-server-updates/management/management-initial-password.txt
Read it on the server with your administrator account; do not send it to support.
The management password is separate from all wallet and node signing keys.

Linux Home: start the installed Home application. It prints the local node
management address and the path to its initial management password. The panel
stays open while disconnected so you can reconnect, open the wallet, check the
signed update channel and control automatic updates. Lock the wallet before
disconnecting or installing an update. Home updates retain the existing data.

Collateral: in the wallet choose My nodes, a registered server and an amount.
Review and confirm. Open that server's management panel, verify the exact wallet
address, node and amount, then approve the request. Keep the wallet unlocked;
it submits and verifies confirmation automatically. Requests expire after five
minutes. Before submission they can be cancelled in the wallet. A submitted
transaction is retried with its saved bytes, never created again automatically.
Server approval and pending submission are not confirmation of a deposit.
Existing collateral and available funds remain separate in the wallet.

Server updates: Check for updates -> Review update -> Confirm. The reviewed
signed version is pinned. Services restart sequentially with quorum, node key
and saved-history checks. A failed step stops the job and restores its prior
service command. Completed earlier service upgrades remain recorded. The panel
reports completion or failure; the local management-last-operation.log contains
bounded diagnostic output. New version directories never overwrite old releases.
